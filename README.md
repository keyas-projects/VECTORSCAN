# VECTORSCAN
VECTORSCAN is a web-based Network Security Assessment and Risk
Management platform designed to help security teams analyze
authorized network targets.

The platform integrates a React-based security dashboard with a
FastAPI backend and Nmap to discover network services, identify
exposed ports, perform OS and service detection, analyze possible
network filtering, and generate security findings with risk
classification.

## Key Features

- Live host detection
- TCP port discovery
- Open, closed and filtered port identification
- Service and version detection
- Operating system fingerprinting
- Possible firewall/filtering detection
- Network architecture inference
- Security configuration checks
- Risk score calculation
- Severity-based findings
- Interactive web dashboard
- Nmap command terminal
- Structured security assessment report
- Authorization confirmation before scanning

  ## Responsible Use

VECTORSCAN is intended for authorized security assessments,
laboratory environments, and systems for which the user has
explicit permission to perform security testing.

Do not use this platform to scan or assess systems without
authorization.
